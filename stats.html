Connect GoatCounter

This page needs a key that lets it read your visitor numbers. You only do this once on each phone or computer.

  1. Open madebyformat.goatcounter.com and tap Settings, then API.
  2. Tap New API token. Name it Stats page and tick only Read statistics.
  3. Copy the token and paste it below.

The token is saved only in this browser. It isn't sent anywhere except GoatCounter.
